# SS Tools — портал

Сайт с авторизацией, админ-панелью и обновлённым чекером модов (Node.js + Express, без внешней БД).

## Запуск

```bash
npm install
npm start            # http://localhost:3000
```

При первом запуске в консоли будет напечатан логин/пароль администратора (пароль нужно сменить при входе).
Свой логин/пароль можно задать заранее:

```bash
ADMIN_USER=command8913 ADMIN_PASSWORD='длинный-пароль' npm start
```

Переменные окружения: `PORT`, `TRUST_PROXY=1` (если за nginx/Cloudflare), `COOKIE_SECURE=1` (при HTTPS), `DB_FILE` (путь к базе).
Все данные лежат в `data/db.json` — делайте копии (или кнопка «Скачать бэкап» в админке).

## Что внутри

- **Авторизация**: пароли в bcrypt, сессии в HttpOnly SameSite=Strict cookie, лимит попыток входа, CSRF-заголовок.
- **Заявки**: новый пользователь регистрируется → статус «Ожидает» → админ одобряет.
- **Доступ**: по разделам (Проверка модов / PowerShell / Site / Everything / ваши), срок действия, блокировка («Забрать доступ») мгновенно закрывает сессии.
- **Админ-панель**: пользователи, разделы и записи (добавить/изменить/удалить/порядок), хэши читов (массовая вставка), правила чекера, журнал действий, бэкап/импорт.
- **Чекер модов v2**: пакетная сверка с Modrinth (SHA-1), движок правил (строки в .class, имена файлов в jar, названия модов), Jar-in-Jar, эвристики (обфускация, встроенные exe/dll, webhook'и, доступ к данным браузера), отчёты txt/json/csv. Файлы не покидают браузер.
